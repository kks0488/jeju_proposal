# 제주집 시공사 선정 — 화면 편집

2026-09-15 사용자 요청: 다른 사람에게 설명하는 공개 검토 자료가 아니라 하백·이아, GAU, 다봄 중 실제 시공사를 선택하는 페이지로 정리한다.

- 제목·상단 이름·본문 큰 제목: `제주집 시공사 선정`.
- 반복되는 미검증·방수·성능 보증·계약 적격 면책 문구와 공개용 안내는 메인·프로젝트 상세·사진 확대에서 제거한다.
- 세 업체의 포트폴리오, 규모·구조·설계·시공 기본 정보, 사진 출처를 유지한다.
- 업체 비교는 포트폴리오 특징과 견적·일정·소장·공종팀을 상담할 내용으로 구성한다. 기존 점수순 설명은 화면에서 제외한다.
- 원문 조사·점수·별도 검토 문서는 삭제하지 않는다. 사진 178개와 모든 이미지 경로를 보존한다. 화면에서 미확정 값을 생략하며 확인된 성능으로 바꾸어 주장하지 않는다.

`node site-v3/selection-edit.cjs`가 기존 정적 갤러리의 문구만 변경한다. 이미지 재수집을 하지 않는다. 향후 이미지 빌드에도 같은 편집을 다시 적용한다. `selection-check.cjs`가 제목, 3개 회사·17개 프로젝트, 사진 178개 디코딩, 필터·확대·모바일 화면을 검사한다.

현재 페이지 위치: https://kks0488.github.io/jeju_proposal/site-v3/published/
공개 접근 설정은 변경하지 않았다. 내부 선택 용도로 문구를 변경하는 작업이며 인증 기능을 추가한 작업은 아니다.
