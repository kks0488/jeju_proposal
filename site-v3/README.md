# 단독주택 비교 · 정적 이미지 갤러리

사용자 요청에 따라 하백·GAU·다봄만 메인에 표시합니다. 아틀리에는 현재 비교 자료가 공동체·협동조합 주택 위주이고 이번 개별 단독주택 조건과 달라 메인에서 제외했습니다. 과거 업체 조사와 ranking.json은 보존합니다.

기존 요청 시 이미지 프록시·동적 변환을 없애기 위해 원문 공개 갤러리의 이미지 파일을 수집하고 크기 최적화 후 `published/assets/`에 저장합니다. 모든 파일은 저장소와 배포 결과에 포함됩니다. 방문 시 외부 원본이나 변환 함수에 연결하지 않습니다.

`build.mjs`: 기존 기초·추가 데이터를 병합하고 3개 업체·17개 프로젝트로 제한합니다. 기존 사진 외에 특정 프로젝트 원문 갤러리의 이미지만 수집합니다. Wix의 초기 3장 외의 공개 갤러리 목록도 읽으며 로고·작은 그래픽은 제외합니다. 저작권·설계·시공 기여를 구분하고 원문 주소·파일 출처·실패 내역을 image-manifest.json에 보존합니다. 원문 도면이 포함될 수 있어 집계는 이미지 수입니다. 전체 업체 실적·모든 사진을 확보했다는 주장은 하지 않습니다.

`browser-test.mjs`: 실제 정적 파일 서버에 Chromium으로 접속해 1440/768/390/320px의 필터·검색·사진 넘김·닫기·깊은 링크·가로 넘침을 검사합니다. 저장된 이미지 전부에 Image.decode()를 실행합니다. 테스트 요청이나 사진을 모의하지 않습니다. 실제 iPhone Safari 검사는 별도입니다.

GitHub Actions는 브라우저 검사 성공 후에만 생성된 정적 페이지·이미지와 검사 JSON을 master에 커밋합니다. 기존 연구 파일은 수정하지 않습니다. 쓰기는 생성된 `site-v3/published/`와 검사 JSON으로 한정하고 fast-forward/rebase 충돌 시 실패합니다. Vercel 정적 배포는 이 결과를 사용합니다.
