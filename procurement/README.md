# 제주 도면 검토·견적 준비

**결론: 자료는 비교견적 준비를 시작할 수준으로 모였지만, 아직 계약용 확정견적을 발행할 기준은 확정되지 않았습니다.** 도면의 용도·발행본·구조/지반 조건부터 정리하고, 모든 업체에 같은 공사 범위와 자재 기준을 주어야 합니다.

검토 기준일 **2026-10-12** · 패키지 **JEJU-RFQ-PREP-20261012-R0** · 상태 **검토 초안 / 미발행**

## 이번 자료에서 먼저 바뀐 판단

건축 DWG에는 건축뿐 아니라 **구조평면·철근배근·RC 구조일반사항**이 들어 있습니다. 창호·마감·배수 상세도 역시 존재합니다. 따라서 없는 도서를 무작정 추가 요구하기보다 **현재 도서의 정합성과 승인 여부**를 확인해야 합니다.

반면 기존 저장소는 주택 계획을 다뤘으나 이번 건축개요에는 **제2종 근린생활시설(사무소)**라고 적혀 있습니다. 연면적은 **345.60㎡**, 건축면적은 **405.06㎡**로 서로 다른 개념입니다. 실제 허가·사용·견적 대상은 건축사에게 확인해야 하며, 어느 한쪽을 임의로 최종 기준으로 채택하지 않았습니다. [도면 근거와 해석](DRAWING-REVIEW.md)

## 경수님이 먼저 준비할 세 가지

1. **건축사에게 발행본 확인 요청:** 용도·면적·견적 대상, 같은 버전의 전체 PDF, 최종 도면목록, 구조/지반 기준, 공종 간 도면 대조를 요청합니다. [보낼 문안과 준비 체크리스트](PREPARATION.md)
2. **건축주 선택표 승인:** 창호·석재·타일·마루·조명·위생기구·가구/가전의 기준 제품 또는 공통 잠정금액, 지급품 범위를 정합니다. 모든 품목을 지금 구매할 필요는 없지만 업체별 가정은 통일해야 합니다.
3. **견적 방식 승인:** 지금은 업체 수량산출 방식의 조건부 예산견적을 받을 수 있습니다. 최종 비교 전에는 공통 수량 또는 대조 완료된 업체 수량으로 통일하고, 동일 공통 질의회신을 발행합니다. [견적요청서](RFQ.md) · [회신 규칙](BID-RETURN.md)

## 완료된 것과 남은 것

원본 3개와 동일한 파일 해시를 확인하고, DWG를 DXF로 변환해 모델공간 문자·도면목록·기기표를 추출했습니다. **89개 고유 도면번호 후보**, **19개 기기표 행**, **25개 확인사항**, **61개 공통 견적항목**을 서로 연결했습니다. 89개는 정식 발행된 PDF 89장을 검증했다는 뜻이 아닙니다.

**미완료:** 공식 PDF 대조, 도면 전체의 시각적 정밀검수, 원본 CAD와 변환 결과의 무손실 검증, 시트별 축척 보정, 창호/철근/콘크리트/마감/배관 등의 확정 물량산출, 설계·법규·구조 적합성 승인. 기기표 수량도 실제 배치 개수와 대조하기 전의 전사값입니다.

공사비·총예산·단가·견적 마감일·착공일은 임의로 채우지 않았습니다. [현재 상태 JSON](data/project.json)

## 보존과 공개 범위

기존 시공사 조사와 순위를 변경하지 않았습니다. 현재 메인 비교업체 하백·이아, GAU, 다봄에 **같은 기준으로 요청하기 위한** 추가 자료입니다. 실제 업체 연락이나 도면 전달은 하지 않았습니다.

이 저장소는 공개입니다. 원본 DWG, 전체 문자 추출, 내부 협의 메모, 개인 연락처, 작성된 업체 견적·가격은 공개하지 않습니다. 여기에는 검토된 근거 발췌와 빈 양식만 둡니다. 실제 배포본은 설계자 정리본을 승인된 업체에 별도 전달합니다.
