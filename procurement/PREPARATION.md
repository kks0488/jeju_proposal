# 업체가 바로 답하려면 — 견적 단계별 준비

**현재 자료로 제안기준의 예산/상세견적 작업을 시작할 수 있지만, 모든 수량과 현장조건이 확정된 고정총액 발주내역서는 아닙니다.** 61개행은 비교목차이며 업체가 도면을 보고 하위물량을 산출해야 합니다.

## 같은 묶음으로 전달할 내용

| 자료 | 상태/처리 |
|---|---|
| R2제안서·A/B회신양식 | 작성됨. 모델/대수는제안이며업체추천허용 |
| DWG3개 | 원본비공개 별도전달; 파일해시/개정확인 |
| 동일개정 PDF | CAD를 사용하지 않는 견적담당자도 읽도록 설계자 출력본 확보 |
| 실명과 실제사용 대응표 | 알려진계획과 최신도면대조; 업무실명만 보고 주거부하를 오해하지 않게 표시 |
| 현장·외부경계·지반/관로 조건 | 제공한자료/미확인 가정분리; 현장설명과 공통질의회신 |
| 마감/가구/가전 범위 | 제안품과실제고정가구치수·지급품설치경계·전기부하명세 확인 |
| 일정·연락처·실제회신처 | 발송시비공개안내. 견적유효/공기·질의마감같이 전달 |

업체가 “도면수량과다르다”, “설비구성변경이낫다”, “해당자재는공급불가하다”라고 바로 적을 수 있도록 A원안을 지우지 않는 B/질의란을 준비했습니다. 모든값을 건축주가 확정할때까지 견적을 막지 않고, 불확실성이금액에어떻게영향을주는지 받습니다.

## 선정 전에 정리

냉난방 부하/배관/전력, 창호 안전/성능·마감두께·가구치수·조건부토공 등 핵심차이를 공통기준으로 정리한 뒤 다시 가격을 맞춥니다. 수신한 다른 B안을 같은 공사라고 가정해 최저총액만 고르지 않습니다. [전체재검토](SPEC-AUDIT.md) · [회신방식](BID-PORTAL.md)
