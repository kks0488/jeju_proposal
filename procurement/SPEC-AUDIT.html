37개 사양 재검토 — 상품 조사와 현장 검증을 구분

지난 R1은 도면 표기와 상품사양을 확인해 가격 기준을 만든 것이지, 우리집의 실별 부하·적정대수·시공 간섭을 모두 검증한 최종안은 아니었습니다. R2는 아래37항목을 다시 검토해 미검증 가정·중복 위험·견적에 필요한 근거를 드러내고, 브랜드/모델/대수/마감을 발주확정이 아닌 제안으로 바꿨습니다.

이 재검토는 문서/가정 감사입니다. 전 도면의 형상·물량·열부하 계산과 전문 설계검증까지 완료했다는 뜻은 아닙니다. 고위험 표시는 기존품목이 반드시 잘못됐다는 판정이 아니라 추가근거가 견적/시공 결정에 중요하다는 의미입니다.

SP-01 · 사용인원·운전조건 미확인

확인 한계: 상시4인 계획은 기존 프로젝트 자료에서 이번에 재확인했다. 방문6인·22/26℃·야간운전은 비교 제안이며 전체실 용도/현재도면 대응은 별도 확인이 필요하다.

R2 처리: 주택 용도·주거 성능은 유지. 인원/재실시간/실별 용도는 확인 전 가정으로 표기하고 대안의 부하조건과 함께 제출.

업체에 받을 근거: 실명→실사용 용도표, 재실/야간운전, 일사·외피·냉난방 설정조건

SP-02 · 구조·지반은 미검증

확인 한계: 도면을 읽었다고 기초/강도/철근/다짐500mm 적정성을 승인할 수 없다.

R2 처리: 도면 구조는 A안 참조로 유지. 구조 변경은 자격있는 책임기술자 검토 대상이며 임의 절감금지.

업체에 받을 근거: 도면·계산서 버전, 지반자료, 공종별 측정/검측·시험 범위

SP-03 · 토질·관저고·공사경계 미확인

확인 한계: 도면 밖 암반과 관로·침투조 처리조건을 동일 단가표만으로 완결총액으로 만들 수 없다.

R2 처리: 도면 확인범위 A금액과 미확인 위험조건/단가/가정수량을 분리. 추가가정은 모든 업체 공통회신.

업체에 받을 근거: 현황·관로조사, 배수경로·구배·침투/월류·복구·암반 조건

SP-04 · 도면재료 유지, 현장 적합성 미검증

확인 한계: 0.7AL 도면 표기는 확인했지만 도장체계·해풍·클립간격·이음상세는 미검증. 차콜색은 제안이다.

R2 처리: 0.7AL 시스템은 A 기준, 동등 내구 대안과 색상 제안 허용. 다른 금속은 접합/부식/보증 차이까지 비교.

업체에 받을 근거: 판폭·클립·풍압·바탕·코팅/보증·단부/관통부 견본

SP-05 · 두께만으로 단열·석재 안전 보장 불가

확인 한계: 100mm EPS·30mm 사비석이 있다고 열교·화재·고정 안전성까지 확인된 것은 아니다.

R2 처리: 외관 의도/도면 부위별재료 A유지. 외단열/고정대안은 열교·치수·법정성능 충족 설명과 증감 제시.

업체에 받을 근거: 외피 구성별 열성능·화재적합성, 고정부 하중/배수·기단 연결

SP-06 · 품질 요구 유지, 접합 시공도 필요

확인 한계: 테이프·실란트 지정만으로 접합 방수 완결성은 알 수 없다.

R2 처리: 창하부 배수와 실내 기밀 등 결과 요구는 유지, 검증된 다른 접합시스템 제안 환영.

업체에 받을 근거: 대표1:1상세·소재호환·물뿌림 시험범위·창호/석재 책임

SP-07 · 예시창호를 전 창호에 확정하면 안 됨

확인 한계: 이건 제품 공개사양 확인은 실제 창ID의 크기·43T조합·Uw·풍압/유리안전·SHGC 검증과 다르다.

R2 처리: 브랜드/시리즈는 A가격 기준의 예시. 창ID별 동급 대안 허용. 유리구성·창전체U·SHGC·기밀·방충/철물·설치까지 비교.

업체에 받을 근거: 창ID·실측개구·개폐/분할·유리두께/중량·안전/풍압 계산, 시험체 성적서

SP-08 · 문 규격·철물 범위 확인 필요

확인 한계: 도면 형식과 임의 추천 철물이 모든 문에 맞는지 미대조.

R2 처리: 도면문은 A기준. 제조가능폭·사용편의·정비성 동등 이상의 제품/철물 제안 허용.

업체에 받을 근거: 문ID·여닫힘/유효폭·방화/피난 해당여부·포켓레일 접근

SP-09 · 125mm 차음벽 일괄 적용 근거 부족

확인 한계: 스터드75+보드양면2겹은 제가 제안한 시스템. 현벽 두께·실면적·문틀/가구 간섭 검증 안 됨.

R2 처리: 125mm는 A비교 구성일 뿐 확정도면 변경 아님. 기존 두께 안의 차음성능 대안과 실치수 영향 필수.

업체에 받을 근거: 벽ID·두께·시험구성·개구/콘센트 차음·문틀/가구 간섭과 실치수 증감

SP-10 · 층고와 덕트/기기 간섭 미검증

확인 한계: CH3200 요청은 존재하나 환기 추가와 배관경로를 통합 조정하지 않았다.

R2 처리: 층고 목표는 유지. 숨은 점검구·기기 철거경로·국소 단차대안은 위치/높이와 함께 승인받기.

업체에 받을 근거: 천장종합도, 보·덕트·냉매/배수·등기구 간섭·교체 접근

SP-11 · 7mm 제품으로 도면을 불필요하게 바꿀 수 있음

확인 한계: T10도면과7mm제품 차이를 보정한다고 썼지만 보정공사 범위/비용·문턱을 검증하지 않았다.

R2 처리: A는 R1의7mm+FL보정 비교값으로 유지하되 확정아님. 도면T10적합 동급제품을 우선 B검토, 동등가격/내구/보수성 비교.

업체에 받을 근거: 원 도면두께·마감FL·접착/바탕·문턱단차·방열/함수·총 설치비

SP-12 · 타일 가격은 실견적 아님

확인 한계: 40,000원은 공통예산이며 제주납품 실견적/재고/적합제품 확보가 확인된 값이 아니다.

R2 처리: 표준규격/무광과 A공통허용액 유지. 적합제품 실제공급·설치견적과 대안단가 별도.

업체에 받을 근거: 제품번호·두께·흡수/미끄럼용도·공급/제주운송·시공·손실 구분

SP-13 · 욕실타일 높이·재단·미끄럼 미검증

확인 한계: 300각/300×600은 제안. 바닥배수/구배·벽높이·타일시험자료 미대조.

R2 처리: 소형 바닥모듈 목표 유지하되 동등안 허용. 실제 마감표와 손실/재단을 기준으로 물량 제출.

업체에 받을 근거: 젖은 맨발 용도·구배/드레인·벽타일 높이·창문공제·끝단

SP-14 · 국내 공급형·방수/접착/줄눈 호환 확인 필요

확인 한계: C2TES1 등급은 도움이 되지만 특정브랜드나 전부 에폭시가 유일한 해법은 아니다.

R2 처리: 요구 부착성/변형흡수·습윤내구 유지. 동일 시스템검증을 갖춘 국내 대안과 샤워줄눈 유지관리 비교.

업체에 받을 근거: 국내TDS·바탕/방수 호환·가사/양생시간·줄눈/신축 이음 상세

SP-15 · 완성 도막과 담수 시점은 제조사에 따름

확인 한계: 2mm·벽2100·24시간담수는 기본 제안이며 모든바탕/기후의 확정 공법이 아니다.

R2 처리: 방수품질·검측 결과는 유지. 대체시스템은 적용부위·도막·보강·양생/시험 기준을 한 묶음으로 제출.

업체에 받을 근거: 국내TDS/승인시방·관통/코너·드레인·도막측정·양생 후 시험

SP-16 · 브랜드·색상은 비교제안

확인 한계: 무광/웜화이트/KCC가 최종 색채 결정은 아니다.

R2 처리: 실내방출·바탕/완성품질 유지, 동등 제품·색상·광도 제안 허용.

업체에 받을 근거: 제품TDS·유효 방출자료·바탕/퍼티/프라이머·샘플/공정

SP-17 · 60mm 걸레받이와 히든몰딩은 미확정 디자인

확인 한계: 문틀/벽면/로봇청소기 등 세부접합 미대조.

R2 처리: A단순디테일 유지, 기성 대안과 청소/내구/비용 제안 가능.

업체에 받을 근거: 치수견본·문틀/바닥접합·시공비·보수접근

SP-18 · 고정가구/주방3개의 물량 근거 부족

확인 한계: 수전3개가 싱크볼3개/주방3개라는 증거는 아니다. 18mm/E0만으로 판재 품질도 완결되지 않는다.

R2 처리: 고정가구 포함원칙 유지. 가구ID/규격/수량표로 가격화하고 싱크볼3은 A임시가정으로 분리, 불일치 수정제안 필수.

업체에 받을 근거: 가구일람/입면·상판길이·모듈/철물·내수/방출시험·주방 실제 수

SP-19 · 카운터·거울·액세서리 중복/치수 미확인
