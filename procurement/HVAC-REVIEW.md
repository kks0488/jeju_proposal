# 에어컨11대 — 필요대수가 아니라 도면 참조수량

**11대가 필요하다는 결론은 아직 없습니다.** 이번에 일람표와1층냉방평면의11개 서로다른IAC문자표기를 대조하고, 정격용량 합계를 검산했습니다. 도면태그 확인과 실제서비스구역/열부하 검증은 다릅니다.

| 확인 | 값 | 해석 |
|---|---|---|
| 도면 실내기 | 11대 | 현재A안 비교 참조; 발주/최소수량 아님 |
| 평면 IAC문자 | 11개 | 모델공간 범위 내 다른TEXT객체. 리더선/실사용 매핑 미검증 |
| 실내기 정격합 | 60.9kW | 산정 냉방부하나 전기소비전력 아님 |
| 실외기 정격합 | 61.6kW (2대) | 기기소비전력은 별도 사양으로 전기부하 산정 |
| 큰 실내기 | 14.5kW×2 =29kW | 실내기 합의47.6%. 이 두 대의 서비스구역·일사를 우선 검토 |
| 단순 면적비교 | 60.9kW÷345.6㎡≈176W/㎡ | 단순 정규화일 뿐 과대판정/적정대수 계산식 아님 |

## 대수만 줄이는 것은 해답이 아님

큰 두 대가 담당하는 개방공간의 부하·기류분배, 각각 닫힌 침실의 독립운전, 간헐사용 다락/보조공간의 목적을 구분해야 합니다. 대수는 유지하면서 용량을 낮추는 안, 불필요한 독립기기를 줄이는 안, 실외기계통/최소운전능력을 바꾸는 안이 서로 다릅니다. 지금6대/7대 같은 다른 숫자로 확정하지 않았습니다.

도면의 업무용 명칭을 실제 재실·가전발열 조건으로 그대로 옮기면 안 됩니다. 실제실사용표, 문닫힘/야간운전, 창면적·방향·U/SHGC·차양, 기밀/단열, 환기와 습도 현열/잠열을 바탕으로 실별계산을 받아야 합니다.

## 업체 냉난방 검토표

`도면실ID / 실제사용 / 면적·높이 / 창·외피·방향 / 재실·발열 / 문닫힘·운전시간 / 산정현열·잠열 / 제안모델·대수 / 정격·최소능력 / 실외기계통 / 배관보정·전원 / 취침기류·소음 / 설치완성비용`

A안은 도면11/2 참조견적이고 B안은 실제주거에 적합한 추천 구성입니다. 냉방·환기·난방/급탕은 검토결과를 필수회신하되, 유지가 적정하다는 결론도 근거와 함께 가능합니다. 기기값뿐 아니라 배관/보온/분기관·드레인·천장/점검구·전원/제어·양중/방진·시운전의 증감까지 비교합니다.

## 다른 설비도 연결해 확인

환기250급3대는 정압/필터/덕트/체적을 검증한 확정대수가 아닙니다. 욕실팬4×220의 단순정격합880m³/h도 실제동시배기량이 아닙니다. 주방후드·급기·문틈·연소설비 급기/역류와 함께 검토합니다. 보일러50,000kcal/h도 건물난방열손실을 계산해 얻은 값이 아니며 급탕피크를 분리해 검토해야 합니다.

## 근거와 한계

[DOE 공식기술자료](https://bsesc.energy.gov/energy-basics/hvac-proper-sizing-hvac-systems)는 먼저 난방/냉방부하를 산정하고 기기/풍량을 선정하도록 설명합니다. 이 방법론을 참고한 것이며 미국법을 한국 의무기준으로 전용하지 않습니다.
