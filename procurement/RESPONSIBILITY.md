# 공종 책임표: 도면 주기를 견적 경계로 연결

**원문에 있는 경계와 제안하는 관리 기준을 구분합니다.** 아래 도면 주기는 해당 부위의 현재 표기이며, 실제 계약 범위는 건축사·발주자·업체가 경계점과 가격행을 확인해 승인해야 합니다. 아직 서명/발행된 책임표가 아닙니다.

## 도면에 명시된 공종 경계

| 작업 | 도면 주기의 담당 | 견적에서 확인할 경계 | 근거 |
|---|---|---|---|
| 오수·배수 배관 | 대지내 오수받이까지 기계설비, 이후 배관 건축 | 오수받이 위치·포함부속·본관 접속·관저고·굴착복구 | [M:EC6D3](EVIDENCE.md#m-ec6d3) |
| 옥외 터파기·되메우기 | 건축 | 배관 견적에 굴착을 다시 포함하는지, 관 포설/보호층/복구 경계 | [M:EC6DE](EVIDENCE.md#m-ec6de) |
| 장비기초 | 건축 | 장비 공급사 하중/앵커 조건, 방진·매립철물의 담당 | [M:EC6DE](EVIDENCE.md#m-ec6de) |
| 난방 온도조절기 배관·배선 | 전기 | 전원선·통신선, 조절기/밸브 공급 및 제어 시운전과 구분 | [M:E903F](EVIDENCE.md#m-e903f) |
| 실내기 점검구 | 건축, 450×450 주기 | 설치 위치·수량·유효 개구·마감·실내기 점검 가능성 | [M:E6723](EVIDENCE.md#m-e6723) |
| 세면대 카운터·화장경 | 건축 | 세면기/수전/배수설치·카운터타공/실링 경계 | [M:EAA76](EVIDENCE.md#m-eaa76) |
| 대지내 오수받이·배수맨홀 | 건축 표기 | 배관 전후 경계와 중복하지 않게 해당 구조물/접속부 확인 | [M:EACA8](EVIDENCE.md#m-eaca8), [M:EACB3](EVIDENCE.md#m-eacb3) |

## 담당을 확정해야 하는 접합 작업

| 접합부 | 확인할 참여자 | 승인할 내용 |
|---|---|---|
| 창호 ↔ 외단열·석재·실내마감 | 건축사·창호·방수·석재 | 앵커·기밀/방수·창하부·열교·마감복구 담당과 검측 |
| 지붕 ↔ 후레싱·낙수·트렌치 | 지붕·건축·토목/설비 | 낙수선부터 침투/방류까지 경로와 높이·월류·접속 |
| 보·슬래브 ↔ 설비 관통 | 구조·건축·기계·전기 | 사전 개구/슬리브 위치·구조보강·충전/방수·무단천공 금지 기준 |
| 실내기 ↔ 천장·전원·드레인 | 냉방·전기·건축 | 장비 공급/설치·전원/제어·점검구·응축수 종단·시운전 |
| 가구/가전 ↔ 전기·급배수 | 건축주·가구·전기·설비 | 지급품의 연결/타공/보양·완성 높이·하자 접수 주체 |
| 인입 ↔ 외부굴착·기관 실비 | 설계자·각 공사업체·발주자 | 신청자·기관비 지급·인입거리·복구·계량기·기존 시설 보존 |

두 번째 표는 **관리 제안**이며 도면에서 최종 담당을 확인했다는 뜻이 아닙니다.

## 승인용 행 양식

`책임ID / 위치·경계점 / 작업 / 설계 확인자 / 공급 / 설치 / 선행공사 / 연결·복구 / 검측 / 비용항목ID / 지급품 여부 / 미해결 RFI / 승인자·일자·ADD-ID`

업체가 같은 작업을 각각 포함했다면 한 행으로 귀속시키고 나머지는 ‘타행포함 + 해당ID’로 표기합니다. 모두 제외했다면 발주 담당이 책임을 배정할 때까지 견적을 완결로 보지 않습니다. 통합 발주에서도 실제 전문공사의 발주·등록·검사 요건 확인을 생략하지 않습니다.
